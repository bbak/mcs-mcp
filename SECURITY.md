# Security Policy

## Supported Versions

Only the latest release receives security fixes.

## Reporting a Vulnerability

Please report vulnerabilities privately through GitHub's
[private vulnerability reporting](https://github.com/bbak/mcs-mcp/security/advisories/new).
Do not open a public issue.

You can expect a first reply within 7 days. Once a fix is released, the
advisory is published with credit to the reporter, unless they prefer
otherwise.
